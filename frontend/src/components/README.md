# 公共组件

骨架阶段为空目录。建议按下表沉淀复用组件，但**出现 2 处以上重复再抽组件**，不要提前抽象。

| 组件 | 使用场景 |
| --- | --- |
| `PageTable` | 列表页「查询表单 + 表格 + 分页」三件套，对接 PageResult 结构 |
| `DictSelect` | 基于接口 8-04 数据字典的下拉选择 |
| `ImageUpload` | 对接接口 8-01 / 8-02，返回 url 写入业务表 |
| `StatusTag` | 状态值 → 颜色标签，文案取模块枚举 |
| `ConfirmButton` | 二次确认的危险操作按钮（删除 / 作废 / 撤销） |
| `EmptyState` | 空数据占位 |
